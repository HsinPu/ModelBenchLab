# 模型管理操作重整

日期：2026-09-24。以下記錄設計依據與已實作的操作流程。

## 調整前觀察

- 「我的模型」、「廠商連線」、「模型目錄」是平行分頁，但加入模型需依序經過連線與目錄，使用者必須自己猜下一步。
- 「連接廠商」、「手動新增」、「新增廠商連線」、「加入模型」分散於不同位置；自訂模型可能不小心走到每個模型各建一組連線的舊流程。
- 模型與連線的大型卡片佔去主要畫面；常用的搜尋、試跑、啟停與加入模型難以快速掃描。
- 模型目錄的連線、同步資訊、篩選列與批次操作擠在清單上方；結果列在首屏只顯示少量。
- 模型不可用時使用籠統的「模型或廠商連線已停用」，無法立即判斷要去哪裡修復；Demo 模型也會顯示這種文字。

## 新資訊架構

保留「模型管理」為主選單，內部改成兩個工作區：

1. **我的模型**（預設）：管理已加入模型；唯一主要按鈕是「加入模型」。
2. **廠商連線**：檢視與維護連線；新增連線是這裡的主要按鈕。

「模型目錄」不再是獨立分頁，而是「加入模型」流程中依所選連線顯示的選擇畫面。OpenRouter 等有目錄的服務顯示目錄；自訂 OpenAI 相容服務顯示手動模型 ID 表單。模型管理不放「建立測試」入口。

## 我的模型

頂部放搜尋欄、連線篩選、狀態篩選和「加入模型」。已有模型時不再顯示佔位很大的介紹橫幅。主清單使用緊湊列：模型名稱與 ID、所屬連線、可用狀態、必要的規格摘要，以及「詳情」和「試跑」。點「詳情」展開右側側欄，顯示 Context、目錄價格、能力、模型 ID、不可用原因及操作；價格標示為目錄參考價，不當作實際費用。

對大量模型採列表；小螢幕改用緊湊卡片。搜尋同時查名稱與模型 ID，篩選條件保留在當前工作區。Demo 模型與真實模型清楚標記。

狀態與修復動作要一一對應：

| 狀態 | 顯示文字 | 直接動作 |
| --- | --- | --- |
| 模型啟用且連線可用 | 可試跑 | 試跑 |
| 模型停用 | 模型已停用 | 啟用模型 |
| 連線停用 | 連線已停用 | 前往該連線 |
| 目錄服務待驗證或金鑰失效 | 連線需驗證 | 前往該連線驗證 |
| 目錄模型下架或不支援 | 目前不可用 | 查看原因與替代模型 |

Demo 模型只可能是「可試跑」或「模型已停用」，不提及廠商連線。

模型詳情另提供「刪除模型」。確認後將模型歸檔並從管理清單移除，保留既有測試結果；有排隊或執行中的工作時拒絕刪除。歸檔模型不能新測或重跑，重新加入相同上游模型會建立新的模型 ID。

## 加入模型流程

一個入口完成所有來源，不讓使用者先判斷應去哪個分頁：

1. 點「加入模型」。先選現有連線；清單列出服務類型、狀態、已有模型數。沒有適合的連線時，從同一流程建立新連線。
2. 新連線只填當前服務需要的欄位。OpenRouter 需要 API Key 並以不產生推論的 metadata 驗證；自訂相容服務需要 Base URL，API Key 可選。不能提供免推論驗證的服務不顯示「驗證金鑰」。
3. 依連線能力選模型：有目錄的服務直接搜尋並勾選；沒有目錄的服務填模型 ID 與顯示名稱。目錄預設只顯示此版支援、尚未加入的模型；免費、作者、能力放在可展開的「進階篩選」。
4. 目錄批次選取使用固定在畫面底部的選取列，顯示已選數量並可查看／移除選項；切換頁碼或篩選不清除選取。
5. 保存後回到「我的模型」，新增列高亮並顯示「試跑模型」。試跑由使用者明確觸發，且提示可能產生費用；不自動發出付費請求。

若連線停用、目錄服務尚未驗證或同步失敗，在原處顯示原因和修復按鈕，保留已填表單與篩選條件。

## 廠商連線

以緊湊列表顯示名稱、服務類型、狀態、模型數、最近檢查時間。每列主要操作為「加入模型」，點「管理」開啟詳情側欄，處理編輯名稱／Base URL、更換金鑰、重新驗證、更新目錄、停用／啟用。OpenRouter 額度資訊放在側欄並明確標成「金鑰額度」，不佔用每列的主要空間。金鑰仍只在輸入時可見，現有連線不回填。

## 實作與驗收

- 前端已拆為模型列表、連線列表、連線表單、加入流程與共用狀態工具；移除 App 中每個手動模型各建連線的舊入口，保留既有資料相容性。
- 沿用連線、目錄、手動／批次加入模型、試跑 API，保留既有模型 ID、連線與測試結果；不需資料庫遷移。後端目錄新增「未加入」與「可選用」篩選，先過濾再分頁，匯入時確認文字輸入／輸出能力；未宣告支援的 temperature / max_tokens 請求欄位會略過。
- 已在既有 OpenRouter 連線檢查目錄搜尋、跨頁與批次選取、進階篩選入口；開啟新連線表單並確認自訂服務的 Base URL 欄位。為避免改動使用者資料或產生費用，未保存測試模型，未觸發付費試跑。
- 桌面與 390px 手機寬度檢查列表和加入流程，確認 Esc 關閉後焦點返回原按鈕。完整驗證結果見 verification.md。
