# 空白回應與逾時診斷

日期：2026-09-25。程式檢查：`check_response()` 對 HTTP 錯誤分類；成功回應若沒有文字，`finish_reason=length` 會歸類為 `no_text_output`；只有 HTTPX 的 TimeoutException 才歸類為 `timeout_uncertain`。這兩條路徑原本沒有保存空白回應的用量和實際模型，且前端「單次逾時」容易誤認為整題總耗時上限。
